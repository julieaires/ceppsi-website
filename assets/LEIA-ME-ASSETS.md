# Guia de Substituição de Assets — CEPPSI

Todos os caminhos no `index.html` já apontam para esta pasta `assets/`. Para atualizar qualquer imagem ou logotipo, basta substituir o arquivo mantendo o mesmo nome (ou atualizar a extensão `.svg` para `.jpg`/`.webp` no `index.html`):

- `assets/logo/logo-ceppsi-principal.svg` — Logotipo oficial colorido (também embutido inline no cabeçalho).
- `assets/logo/logo-ceppsi-branco.svg` — Versão branca do logotipo para fundos escuros.
- `assets/hero/hero-atendimento.svg` — Foto principal do Hero (recomendado: `1480x620px`).
- `assets/servicos/avaliacao-neuropsicologica.svg` — Imagem do card central em destaque (recomendado: `800x480px`).
- `assets/equipe/` — Fotos individuais dos 7 especialistas (`600x700px`, retrato vertical com rosto centralizado no topo).
- `assets/blog/` — Capas dos 3 artigos do blog (`800x500px`).
